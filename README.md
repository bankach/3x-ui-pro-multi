# 3x-ui-pro-multi

Автоматическая установка 3x-ui с nginx, SSL, диагностикой и подпиской для Happ / INCY.
Основа: [mozaroc/3x-ui-pro](https://github.com/mozaroc/3x-ui-pro).

Дополнительно создаются **Hysteria2, Shadowsocks 2022 и VMess WebSocket + TLS**.
Они управляются прямо из 3x-ui и попадают в общую подписку вместе с исходными включёнными протоколами.
Первый клиент создаётся автоматически.

## Установка

Нужен чистый VPS: Debian 12/13 или Ubuntu 24.04/26.04, root-доступ, два разных домена с A-записями на IPv4 VPS.
Домены должны работать напрямую, без Cloudflare Proxy.

Репозиторий: `bankach/3x-ui-pro-multi`, ветка `main`.

Шаг 1 — скачать скрипт:

```bash
wget -O x-ui-latest.sh https://raw.githubusercontent.com/bankach/3x-ui-pro-multi/main/x-ui-latest.sh
```

Шаг 2 — запустить:

```bash
sudo bash x-ui-latest.sh
```

Скрипт спросит домены. Можно передать их сразу:

```bash
sudo bash x-ui-latest.sh -subdomain panel.example.com -reality_domain reality.example.com
```

Установщик содержит все нужные шаблоны и исходники. Остальные серверные компоненты скачиваются при установке.
Версия панели зафиксирована: **3x-ui 3.8.5 / Xray 26.9.9**.
Существующая база 3x-ui не перезаписывается: при её обнаружении новая установка прекращается.

## Что добавлено

| Протокол | Порт по умолчанию |
|---|---|
| Hysteria2 + TLS | 443/UDP |
| Shadowsocks 2022 AES-128-GCM | 8388/TCP и UDP |
| VMess WebSocket + TLS | 443/TCP через nginx |

Установщик сохраняет VLESS REALITY, VLESS WS, отключённый по умолчанию XHTTP, Trojan gRPC,
Clash-шаблон, сайт-прикрытие, диагностику и бэкап из исходного проекта.

Другие порты: `-hy2_port 8443 -ss_port 8389`.
При нестандартном SSH-порте заранее разрешите его в UFW. Внешний firewall в кабинете VPS настраивается отдельно.

## Happ / INCY

После установки скрипт выдаст HTTPS-ссылку подписки. Добавьте её в приложение и обновите подписку.
Отдельные ссылки сохраняются на VPS в `/root/3x-ui-pro-multi/links.txt`, адрес подписки — в `access.txt` рядом.
Для этих протоколов нужна актуальная версия приложения.

## Патч и просмотр исходников

Применение встроенного патча к этой сборке:

```bash
sudo bash x-ui-latest.sh --patch
```

Он сохраняет nginx-маршрут VMess. Патч не добавляет протоколы в чужую существующую установку.

Распаковка всех исходников без установки, в новый каталог:

```bash
bash x-ui-latest.sh --extract-only ./review-source
```

Внутри — читаемые shell/Python-скрипты, шаблоны, тесты и полная инструкция.
Контрольная сумма SHA256 встроенного архива проверяется перед распаковкой.

## Проверено

Проверены API настоящей 3x-ui 3.8.5, экспорт подписки, пять автоматических тестов
и передача данных по Hysteria2, Shadowsocks и VMess, включая nginx + TLS.
Полная установка на Linux VPS, Let's Encrypt, systemd/UFW и импорт в интерфейсе Happ/INCY
в рабочей среде автора этой модификации не проверялись.

Это самостоятельная модификация исходного проекта, не официальный релиз mozaroc или 3x-ui.
